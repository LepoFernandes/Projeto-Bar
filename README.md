# 🍻 Projeto Bar

## 🚀 Sobre o projeto

Site simples desenvolvido para representar meu bar e mercado, usado como prática para **aprimorar habilidades em HTML e CSS**.
O objetivo foi treinar estruturação de páginas, navegação e responsividade.

## 🌐 Demonstração

👉 [Acesse a página no GitHub Pages](https://lepofernandes.github.io/Projeto-Bar/)
👉 [Repositório no GitHub](https://github.com/LepoFernandes/Projeto-Bar)

## 🛠 Tecnologias

* HTML5
* CSS3

## ⚙️ Como rodar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/LepoFernandes/Projeto-Bar.git
   ```
2. Acesse a pasta do projeto:

   ```bash
   cd Projeto-Bar
   ```
3. Abra o arquivo `index.html` no navegador.

## 📌 Aprendizados

Esse projeto me ajudou a:

* Melhorar o uso de HTML e CSS em layouts mais completos
* Trabalhar com estilização e navegação entre páginas
* Praticar responsividade e design adaptado para diferentes dispositivos
